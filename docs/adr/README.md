# 架构决策记录（ADR）

一篇一个决定。格式固定四段：**背景 / 候选方案 / 决定 / 后果**。

写 ADR 的门槛是「这个决定以后可能被质疑」。如果你能想象三个月后自己问「当初为什么这么搞」，
就值得写一篇。不要为显而易见的实现细节写 ADR。
